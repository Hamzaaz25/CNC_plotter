# CNC Plotter Automation

## Overview :

This project focuses on automating the workflow of a CNC plotter.
During the construction of our plotter, 
we faced a repetitive and time-consuming process every time we wanted to start a new drawing. 
To solve this, we developed a software tool that streamlines the entire procedure.

With this application, you can:

* Select an image from your device

* Capture a new image using your webcam

* Choose from multiple drawing styles

* Send the processed output directly to the CNC plotter

Our goal is to simplify the drawing process, reduce manual setup time, and provide a smoother experience for users working with custom-built CNC plotters.
